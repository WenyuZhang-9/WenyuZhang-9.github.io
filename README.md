# Wenyu Zhang — Academic Website

Personal academic website for Wenyu Zhang.

## Structure
- `index.html` — homepage
- `research.html` — research agenda
- `publications.html` — publications and manuscripts
- `cv.html` — academic CV in web format
- `assets/styles.css` — visual styling
- `assets/site.js` — navigation and footer behavior

## Deployment
This repository is intended for GitHub Pages deployment.

The site is fully static and can also be mirrored on any static hosting service.
